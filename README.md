# 📩 Spam Detection App

A **Spam Detection Web Application** that classifies messages as **Spam** or **Not Spam** using Python and Machine Learning, with a Flask-powered backend and a simple web interface.

## 🚀 Tech Stack

* 🐍 Python
* 🌐 Flask
* 🎨 HTML & CSS
* ⚡ JavaScript
* 🤖 Machine Learning

## ✨ Features

* Detects **Spam / Not Spam** messages
* Interactive web interface
* Flask backend for predictions
* Machine learning-based classification
* Responsive and user-friendly UI

## 🔄 How It Works

```text
User Message
     ↓
HTML / CSS / JavaScript
     ↓
Flask Backend
     ↓
ML Model
     ↓
Spam / Not Spam
```

```bash

cd spam-detection-app

python app.py
```

```text
http://127.0.0.1:5000/
```
